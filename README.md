# Create Shift Report

A prototype for closing managers at bars and clubs: at 3am, after a 10-hour shift, the night's report is mostly drafted already, the manager talks it through with an AI agent, and is told to go home. Tonik · Senior Product Designer: Design & Build task, by Filip Wierzbiański.

- **Prototype:** https://shift-report-ochre.vercel.app (Polish: https://shift-report-ochre.vercel.app/pl)
- **Presentation:** https://shift-report-ochre.vercel.app/deck (arrows to move, F for full screen)
- **Scope (deliberately raw):** [SCOPE.md](SCOPE.md)

## What to look at

| Story | Link |
|---|---|
| The bar and the door reported an incident during the night | `/manager` |
| Nobody on the team reported anything | `/manager?night=solo` |
| The door reports an incident with one gesture (Mike) | `/staff?role=security` |
| The owner reads the morning digest (Dana) | `/owner` |

The manager's flow is a web app on the office laptop (`?device=phone` shows the same flow on her phone): the agent opens with one line, the manager talks, the agent asks only what the insurer and the morning team still need, and the last part of the conversation is the decision ("Yes, I accept everything"). The report, its 13 optional sections and a helper question for each, waits folded on the right. Notes under the device explain each screen for reviewers; they are not part of the product.

## How it's built

- **Next.js 16** (App Router), **React 19**, **Tailwind CSS v4**, a few **shadcn** primitives. One look ("Studio noir"), the agent is a canvas animation (`src/components/agent`).
- **Claude API** (`src/app/api/extract`): the manager's story goes to Claude with one Zod schema; every fact must quote the words it came from. Without `ANTHROPIC_API_KEY`, or if the call fails, a scripted answer for the demo night is used, so the prototype never dies on bad wifi.
- **The agent's voice**: every scripted line is pre-recorded with neural voices (`public/voice`, generated by `scripts/voice`), so it speaks with no key and no cost. With `ELEVENLABS_API_KEY`, other lines go through ElevenLabs (`src/app/api/tts`); without either, the browser's own voice.
- **Polish version**: `/pl` sets a cookie; text is translated from an English-keyed dictionary (`src/lib/pl.json`), amounts become złoty.
- **Data**: the night (POS, door counter, rota, staff reports, incident fields, recall questions) lives in `src/lib/night.ts`. Photos of the night were generated in OpenArt; file handling is faked, as the brief allows.

## Run it

```bash
npm install
npm run dev    # http://localhost:3000
```

Optional `.env.local`:

```
ANTHROPIC_API_KEY=...      # real Claude extraction instead of the scripted night
ELEVENLABS_API_KEY=...     # voice for lines without a recording
```
